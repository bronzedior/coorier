# coorier
Our app is your friend who wants you to be out there. They’re nosy about your daily life, and you’d like to share yours too.

## Setup

The Xcode project (`Coorier/Coorier.xcodeproj`) is **not committed** — it is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) (use version 2.46.0) from `project.yml` at the repo root. The `--project Coorier` flag makes it generate inside the `Coorier/` folder:

```sh
xcodegen generate --project Coorier --project-root Coorier
```

Run this after cloning and whenever `project.yml` changes. Then open `Coorier/Coorier.xcodeproj`.

### Signing (each developer uses their own team)

Signing team is **not** in `project.yml` — it comes from a per-developer xcconfig that is gitignored:

1. `cp Coorier/Developer.xcconfig.example Coorier/Developer.xcconfig`
2. Set `DEVELOPMENT_TEAM` to your own team ID (Xcode → Settings → Accounts → your Apple ID → Team; personal teams work, they show as "Your Name (Personal Team)").
